# Map controls

Bottom bar buttons in IRIS:

| Button | Style |
|--------|--------|
| **DARK** | OpenFreeMap dark vector |
| **LIGHT** | OpenFreeMap liberty (streets) |
| **OSM** | OpenStreetMap raster |
| **TOPO** | OpenTopoMap terrain |
| **SAT** | Esri World Imagery 3D globe |
| **HYBRID** | Esri imagery + place labels |
| **3D** | Dark globe |

## Full app

Place `IRIS-CyDoxer-GodEye-China.html` in the repo root (single-file PWA, ~1.3 MB).
Open it directly in a browser — no build step.
