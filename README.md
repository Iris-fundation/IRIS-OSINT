# IRIS — OSINT

Browser-based Open Source Intelligence tool (single-file HTML).

## Features

- Global MapLibre map (**DARK / LIGHT / OSM / TOPO / SAT / HYBRID / 3D** globe)
- CCTV clusters, transit layers, ADS-B / AIS hooks
- GEO & CyDoxer probabilistic OSINT (in-browser)
- God's Eye HUD / sensors
- IQ by country 2026 map (International IQ Test public ranking, desktop)
- China OSINT coordinate tools (desktop)

## Usage

1. Download `IRIS-CyDoxer-GodEye-China.html`
2. Open in Chrome / Firefox / Edge (desktop recommended for full features)
3. Use the **bottom map buttons** to switch basemaps
